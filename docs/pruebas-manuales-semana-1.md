PFY2202 · Experiencia 1 · Forma B · Aula Verde

## Preparación

En `C:\Dev\Duoc\DFEII\DFE_II_supermercado`, ejecutar:

```powershell
npm ci
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

Si las dependencias ya están instaladas, basta con el segundo comando. Usar Chrome o Edge para las pruebas con DevTools. La base es <http://127.0.0.1:5173/>. No habilitar bloqueos ni sustituciones de respuesta salvo en las pruebas que lo indiquen. Utilizar únicamente datos ficticios en el formulario.

## Sustituciones seguras de respuesta

Para las pruebas 16–18, usar **Local Overrides** de DevTools, sin editar los JSON del repositorio:

1. Abrir DevTools (F12), entrar en Network/Red y recargar la página que consume el archivo.
2. Localizar `productos.json` o `sucursales.json`, pulsar el botón derecho y elegir **Override content / Sustituir contenido**.
3. Cuando se solicite, seleccionar una carpeta temporal **fuera del repositorio**. Dar acceso solo a esa carpeta. No seleccionar `public/data`.
4. Modificar la copia de respuesta abierta en DevTools, guardar con Ctrl+S y recargar la página.
5. Al terminar cada prueba, ir a Sources/Fuentes → Overrides, desmarcar **Enable Local Overrides** y recargar. Confirmar que regresan 12 productos o tres tiendas. Al reactivar una sustitución para otra prueba, reemplazar completamente su contenido.
6. Al terminar todas las pruebas, deshabilitar Overrides y los bloqueos de solicitudes; cerrar DevTools. Las copias temporales pueden borrarse desde esa carpeta fuera del proyecto. Nunca usar «Save for overrides» sobre archivos del repositorio ni modificar las fuentes de la aplicación.

Esta técnica solo sustituye la respuesta en el navegador de prueba. Referencia: [Local Overrides de Chrome DevTools](https://developer.chrome.com/docs/devtools/overrides). Para bloqueo de solicitudes, [referencia de Network](https://developer.chrome.com/docs/devtools/network/reference/#block-requests). Los nombres pueden variar con el idioma y la versión.
